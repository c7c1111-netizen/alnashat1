# منصة النشاط الطلابي

منصة لإدارة النشاط الطلابي في المدرسة. تغطي دورة العمل كاملة: التخطيط، واختيار البرامج، والتوزيع الذكي، والإسناد للمعلمين، والجدولة، والمراجعة، والتنفيذ، والتوثيق بالشواهد، والتقارير، والتصدير.

- **الرابط:** `https://c7c1111-netizen.github.io/alnashat1/platform/`
- **الكود المصدري:** هذا المجلد (`platform-src/`)
- **الملفات المبنية الجاهزة للنشر:** `../platform/`

## التشغيل والبناء

```bash
npm install
npm run dev          # تطوير محلي (Vite)
npm run build        # بناء إلى ../platform (Vite)
npm run build:esbuild  # بناء بديل بدون Vite (esbuild مباشرة)
npm test             # اختبارات المنطق
```

> النسخة المنشورة حاليًا بُنيت بـ `build:esbuild` (نفس مخرجات Vite: ملف `assets/app.js` وملف `assets/app.css`، مع أجزاء تُحمّل عند الحاجة).

## البنية

```
public/
  data/                 ← بيانات منفصلة عن الكود وتنحدّث بدون إعادة بناء
    domains.json          المجالات (الاسم، الأيقونة، اللون، الهدف)
    programs.json         البرامج وعدد حصصها لكل مرحلة (الدليل التفسيري 1448هـ)
    stages.json           المراحل والصفوف
    school-seed.json      الفصول والمعلمون الأوليون (تُنسخ للإعدادات أول مرة)
    calendars/
      index.json          قائمة التقاويم
      1448-1449.json      تقويم العام: الأسابيع، الأيام، الإجازات، المناسبات (بتكرار سنوي)
  templates/
    official-plan.docx    قالب Word الرسمي «خطة برامج النشاط الطلابي»
  sw.js, manifest.webmanifest, icons/   ← العمل بدون إنترنت (PWA)
src/
  state/        الحالة المركزية (reducer واحد) + نموذج البيانات + الترحيل بين الإصدارات
  storage/      IndexedDB (البيانات والشواهد) + النسخ الاحتياطي + الترحيل من الأداة السابقة
  scheduler/    محرك التوزيع الذكي
  validation/   محرك التعارضات
  services/     الفهرس والتقويم، محرك نسبة ١٠٪، المؤشرات والتنبيهات، التقارير، المساعد الذكي
  export/       تعبئة قالب Word، تقارير Word، عرض الطباعة PDF، الصور، التنزيل
  components/   مكونات الواجهة (أزرار، بطاقات، نوافذ، تنبيهات منبثقة…)
  pages/        الصفحات + معالج الخطة (wizard/)
  utils/        العربية (الأرقام والتواريخ)، التنظيف والتحقق
tests/          اختبارات المنطق (node --test)
```

## إضافة عام دراسي جديد

1. انسخ `public/data/calendars/1448-1449.json` إلى ملف جديد، مثل `1449-1450.json`.
2. عدّل فيه الأسابيع والأيام والإجازات. المناسبات تبقى كما هي لأنها تتكرر سنويًا (`recurrence`).
3. أضف الملف إلى `calendars/index.json`.
4. اختر العام الجديد من «الإعدادات ← المدرسة».

## قالب Word

- **كيف يتعبّى القالب:** المحرك (`src/export/officialDocx.js`) يتعرّف على جداول القالب من عناوينها: «البرنامج / الصف / اسم المعلم»، و«جدول اسناد…»، و«المرحلة». ويكتب في الخانات فقط بدون أي تغيير في التصميم.
- **تغيير القالب:** يمكن استبدال القالب من «الإعدادات ← القالب» برفع نسخة معدّلة تحتوي نفس الجداول، بدون أي تعديل في الكود.

## الأمان

- **عرض النصوص:** كل النصوص تُعرض عبر React، فتُهرَّب تلقائيًا. المنصة لا تستخدم `innerHTML` مع بيانات المستخدم.
- **الروابط:** تُقبل روابط `http` و `https` فقط.
- **أسماء الملفات والنسخ المستعادة:** تُنظَّف وتُتحقق قبل الاستخدام.
- **الملفات التنفيذية:** المنصة ترفض رفعها كشواهد.

## مستقبلًا: الحسابات السحابية

- **طبقة التخزين:** التخزين معزول في `storage/db.js` بواجهة واحدة، فتنضاف المزامنة بدون تغيير الصفحات.
- **الأدوار المخططة:**

  | الدور | الصلاحيات |
  |---|---|
  | المدير | مشاهدة واعتماد |
  | رائد النشاط | إنشاء وتعديل ومتابعة |
  | المعلم | خططه، وتحديث التنفيذ، والشواهد |

- **المساعد الذكي:** يعمل حاليًا بمحرك قواعد داخلي بدون إنترنت (`services/assistant.js`)، وواجهته جاهزة لاستبداله بنموذج ذكاء اصطناعي.
