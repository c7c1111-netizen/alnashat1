# منشئ خطة النشاط الطلابي

نظام يملأ **ملف Word الأصلي نفسه** (MASTER TEMPLATE) ببيانات الخطة آليًا، دون إعادة تصميم أو إعادة بناء أي جدول.
الناتج: `خطة برامج النشاط الطلابي - [اسم المدرسة].docx` + نسخة PDF للطباعة.

> المعيار: ليس «نسخة تشبه الملف»، بل **نفس ملف Word الأصلي تمت تعبئته آليًا** — ويثبت ذلك اختبار تطابق آلي.

## التشغيل

```bash
cd activity_plan
pip install -r requirements.txt
python app.py            # ثم افتح http://127.0.0.1:5000
```
على ويندوز: `run.bat`، وعلى لينكس/ماك: `./run.sh`.

لتصدير PDF يلزم أحد الخيارين:
- **Microsoft Word** (ويندوز) مع `pip install docx2pdf` ← مطابقة 100% لأن Word يرسم الملف بخطوطه الأصلية.
- **LibreOffice** ← يعمل على أي نظام. إن لم تكن خطوط Word مثبتة يستخدم بدائل قريبة القياس؛
  لأفضل نتيجة انسخ `majalla.ttf` و `arial.ttf` و `micross.ttf` من `C:\Windows\Fonts` إلى مجلد `fonts/`.

## خطوات الاستخدام

| الخطوة | ما يحدث |
|---|---|
| 1. بيانات المدرسة | المنطقة، اسم المدرسة، المرحلة (قائمة)، العام الدراسي، الفصل، تاريخ بداية الأسبوع الأول (هجري). يظهر أسفلها أين سيُكتب كل حقل. |
| 2. المسؤولون | اسم رائد النشاط واسم المدير — مرة واحدة فقط، ويُملآن في كل مواضعهما. |
| 3. المعلمون | الاسم، المادة، المرحلة، الصفوف، عدد حصص المادة. يحسب النظام 10% (تقريب لأسفل)، المسند، والمتبقي. اضغط على معلم لعرض برامجه. |
| 4. البرامج | البرنامج، المجال، المعلم، عدد الحصص، تاريخ البداية/النهاية، الحصة، الصفوف، الهدف، الوصف... أو **استيراد ملف**، أو الإضافة من مكتبة البرامج. |
| 5. الجدولة | توزيع تلقائي على الأيام والحصص (بلا تضارب ومع تخطي أيام الإجازات المحجوبة في القالب)، مع إمكانية تعديل أي خانة يدويًا. |
| 6. المراجعة | الأخطاء والتنبيهات، جدولا الإسناد والمجالات كما سيُكتبان، و**معاينة الخطة** (صفحات ملف Word الناتج نفسه). |
| 7. التصدير | تصدير Word، تصدير PDF، اختبار التطابق، تصدير قواعد البيانات، النسخ الاحتياطي. |

الحفظ تلقائي. يمكن حفظ أكثر من خطة، ونسخ خطة، وتعديل خطة قديمة وإعادة تصديرها (قائمة الخطط أعلى الصفحة).

## استيراد البرامج
يقبل: **Excel (xlsx)**، **CSV**، **Word (docx)**، **PDF**. يكفي أن يحتوي الملف جدولًا بصف عناوين فيه
«اسم البرنامج»، والأعمدة الأخرى اختيارية بأي ترتيب:
`مجال النشاط، الهدف، وصف مختصر، الفئة المستهدفة، الصفوف المستهدفة، المعلم المسؤول، عدد الحصص، تاريخ البداية
(أو تاريخ التنفيذ)، تاريخ النهاية، وقت التنفيذ، الحصة، ملاحظات`. نموذج جاهز: `samples/نموذج استيراد البرامج.xlsx`.

- الملف المرفوع هو المرجع: الأسماء والتواريخ تُنقل حرفيًا ولا يُخترع أي برنامج.
- التاريخ الميلادي في الملف يُحوّل داخليًا إلى هجري ويُبلغ المستخدم بذلك.
- قبل التطبيق تُعرض **التعارضات**: برنامج مكرر ببيانات مختلفة، برنامج موجود في الخطة بتاريخ/حصص مختلفة،
  تاريخ خارج الفترة أو غير صحيح، مجال غير موجود في القالب، معلم غير موجود (يُضاف عند الموافقة).
- ملفات PDF: قد تُخزن بعض ملفات PDF الحروف العربية بترتيب بصري؛ يعالج النظام ذلك وينبهك لمراجعة الأسماء.
  Excel/Word أدق دائمًا.

## قواعد مهمة مطبّقة
- **التواريخ هجرية** (تقويم أم القرى) بصيغة `10/3/1448هـ`، والأيام بالعربية. الميلادي داخلي فقط.
- **نسبة 10%**: المتاح = ⌊عدد حصص المادة × 10%⌋؛ مثال 90 ← 9، وبعد برنامج من 3 حصص يبقى 6.
- **قبل التصدير** يمنع النظام: برنامجًا بلا اسم أو تاريخ أو معلم، تجاوز حصص المعلم، تاريخًا خارج الفترة، تضاربًا في
  نفس الحصة، اسم مدير/رائد/مدرسة فارغًا، مرحلة غير محددة، أو تجاوز سعة جداول القالب (17 صف إسناد، 9 برامج لكل مجال).
- **النص الطويل** لا يوسع الجدول: يُصغّر خطه داخل خليته فقط بحسب ارتفاع الصف في القالب.

## اختبار التطابق
من الواجهة (التصدير ← تشغيل الاختبار) أو:
```bash
python tools/verify_output.py "output/خطة برامج النشاط الطلابي - مجمع أبو بكر الصديق التعليمي.docx"
python -m pytest -q tests
```
يتحقق من: تطابق كل أجزاء الحزمة غير المعدلة بايتًا ببايت (الصور، الأنماط، السمة، التذييل...)، عدم وجود أي
تغيير في XML خارج مواضع البيانات، عدد الأقسام والجداول والصفحات، حجم الصفحة، الهوامش، عرض الأعمدة، ارتفاع الصفوف،
الخلايا المدمجة، الخطوط، الألوان، الصور، الأشكال ومربعات النص، فواصل الصفحات؛ ثم يحول القالب والناتج إلى PDF بنفس
المحرك ويقارن صفحةً صفحة: كل حدود الجداول والخلفيات والأشكال (عناصر متجهة) ومواقع الصور، ونسبة البكسلات
المتغيرة خارج مواضع النص. التقرير: `output/verification/report.html` (صور: القالب ← الناتج ← الاختلافات بالأحمر).

## المخرجات التجريبية (`output/`)
أُنشئت بـ `python tools/build_demo.py`:
- `خطة برامج النشاط الطلابي - مجمع أبو بكر الصديق التعليمي.docx` و `.pdf`
- `قاعدة بيانات البرامج والمعلمين.xlsx` و `قاعدة بيانات البرامج.csv` و `قاعدة بيانات المعلمين.csv`
- `verification/report.html` تقرير اختبار التطابق

البيانات التجريبية: المدرسة «مجمع أبو بكر الصديق التعليمي»، المرحلة المتوسطة، رائد النشاط «وليد أحمد»، المدير
«أحمد سالم» (تجريبي)، ثمانية معلمين تجريبيين. برامج الاصطفاف والصلاة مقروءة كما هي من القالب، وبرامج الحصص
مأخوذة أسماؤها وأعداد حصصها من مكتبة البرامج الموجودة في المستودع (`index.html`).

## التوسع لاحقًا
- **قالب جديد/محدّث**: استبدل `templates/master.docx` (أو حدد `PLAN_TEMPLATE`)؛ المواضع تُكتشف بالمحتوى.
- **مجال جديد**: أضفه إلى `EXTRA_DOMAINS` في `engine/model.py` (يظهر في البرامج والجدولة؛ جدول المجالات يلتزم بمجالات القالب).
- **مرحلة جديدة**: أضفها إلى `STAGES` في `engine/model.py`.
- **عام/فصل/تواريخ جديدة**: من خطوة بيانات المدرسة (تاريخ بداية الأسبوع الأول يعيد حساب كل التواريخ).
